# 全部未整本读完的书：文字迁移包

共 **501 本**，排除有明确整本已读记录的 **192 本**。
下载压缩包合计 **356.35 MiB**，共 **9 卷**，每卷不超过 40 MiB。
OCR/原生文本、既有阅读成果、候选、来源映射和断点均保留；不含原书PDF/图片。
这不是只导出“未分配”的旧158本包，也没有因部分L2或本机认领而排除书籍。

```bash
python3 unpack.py
```

脚本验证全部分卷SHA-256，合并并解压到 `reading/`。不会修改原电脑的任何任务或认领。
把 `reading/开始阅读.txt` 发给另一台机器的阅读对话，告知解压根目录。
先复用已有成果和断点，再读未覆盖原文；规则只加载一次。不选模型，不新增额度门槛。

注意：本包是快照，**包含本机仍在读和旧外发包的书**，不授予抢占本机认领的权限。
其他机器的成果保存在自身 `outputs/` 和 `checkpoints/`，返回时按来源区间去重合并；不要覆盖源电脑数据库。
